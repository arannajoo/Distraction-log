# 전환 기록기 (Switch Log)

작업 중 주의가 전환되는 순간을 관찰·기록하는 개인용 웹앱입니다.
생산성 점수가 아니라, 전환을 일으키는 인지적 과정(지루함, 어려움, 아하!, 곁가지 호기심, 공유 충동, 압도감 등)을 관찰하는 도구입니다.

## 사용 흐름
작업 시작 → 작업 → 전환을 알아챔 → 앱으로 돌아와 기록

## 파일
- `index.html` — 앱 전체 (HTML·CSS·JS 한 파일, 빌드 불필요)

## GitHub Pages로 올리기
1. 새 저장소를 만들고 `index.html`, `README.md`를 업로드합니다.
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 지정하고 저장합니다.
3. 1–2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.
4. 폰에서 열고 브라우저 메뉴의 **홈 화면에 추가**를 누르면 앱처럼 쓸 수 있습니다.

## 데이터
- 모든 기록은 **그 브라우저의 localStorage**에만 저장됩니다 (키: `switchlog.v2`). 서버·로그인·추적 없음.
- 기기·브라우저마다 기록이 따로 저장됩니다. 주소가 바뀌면(예: 다른 사이트에서 GitHub Pages로 이동) 기존 기록이 보이지 않으니, 옮기기 전에 **데이터 탭 → JSON 백업 내보내기** 후 새 주소에서 **불러오기** 하세요.

## 수정하기 쉬운 곳
- 카테고리(트리거·목적지·전환 방식 등): 스크립트 맨 위 `CONFIG` 객체
- 데이터 구조: `CONFIG` 아래 "데이터 모델 (v2)" 주석과 `blankEvent()`
- 기존 `code` 값은 저장 데이터에 쓰이므로 바꾸지 말고, `label`/`desc`만 고치거나 새 항목을 추가하세요.

## 앱으로 설치 (PWA)
`manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`도 `index.html`과 **같은 폴더(저장소 최상단)**에 올려야 합니다.
이 앱은 고유 id(`switch-log`)와 범위(`./`)를 가지므로, 같은 GitHub 계정의 다른 앱과 설치가 겹치지 않습니다.
